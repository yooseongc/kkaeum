# 깨움

갤럭시 탭 S8+용 개인 알람 앱. 광고·로그인·자체 서버 없이 작동합니다.

## 다운로드

[깨움 1.0.0 릴리즈](https://github.com/yooseongc/kkaeum/releases/tag/v1.0.0)에서 `kkaeum-1.0.0.apk`를 설치할 수 있습니다.
Android 12(API 31) 이상이 필요하며, Galaxy Tab S8+ / Android 16에서 확인했습니다.
첫 실행 후 정확한 알람·알림·잠금 화면 표시 권한을 허용하고 설정의 ‘알람 점검’을 확인하세요.

현재 APK는 개인 사용을 위해 만든 디버그 서명 빌드입니다. 서명 키는 저장소에 포함하지 않습니다.
직접 빌드한 APK는 서명이 달라 배포 APK 위에 업데이트 설치되지 않을 수 있습니다.

## 현재 버전: 1.0.0

- 시·분 휠, 알람 이름/복제, 요일 반복/일회성, 다음 실행 날짜와 남은 시간
- 가로 목록/편집 화면과 넓이에 따른 설정 카드 두 열 배치
- 알람별 내장 5종/시스템 소리/내 음원, 미리 듣기, 진동
- 첫 잠금 해제 전 재부팅 복구 및 프로세스 종료 시 미션 진행 복원
- 한 자리/두 자리 덧셈 1~10문제. 풀이 중 무음, 무입력 후 재울림
- 다시 울림 간격·횟수, 다음 한 번 건너뛰기와 취소
- 한국 공휴일 건너뛰기, 전역 날짜 예외, 오프라인 캐시 및 하루 단위 갱신
- 예약에 영향을 주지 않는 미션 시험

## 1.0 마무리

- 설정 → 알람 점검: 정확한 알람, 알림(울리는 알람 채널 포함), 잠금 화면 표시, 기기 알람 음량.
- 목록에는 문제가 있을 때만 확인 안내. 점검은 현재 설정 확인이며 실행 보장 표시는 아님.
- 음량은 기기가 제공하는 최소~최대 범위 사용. Tab S8+는 1~15.
- 다음 알람에는 이름·오늘/내일·날짜·남은 시간 표시, 다시 울림 구분.
- 큰 글씨와 낮은 창에서 목록에 접근하도록 시계와 다음 알람 카드도 함께 스크롤.
- 스위치, 더보기, 증감 버튼, 음량 조절의 접근성 이름 추가.
- 개인 설치용 APK이며 기존 설치와 동일한 디버그 서명으로 업데이트 가능.

## 0.5 화면과 설정

- 첫 화면은 시계와 알람 목록. 알람 선택 시 편집 화면, 전역 설정은 별도 화면.
- 기기 설정 따름 / 라이트 / 다크, 12·24시간 형식, 초 표시.
- 공휴일 건너뛰기는 각 알람에서 선택. 전역에서는 공휴일 목록·갱신과 날짜별 예외 관리.
- 복제·삭제는 각 알람의 더보기 메뉴.

## 0.4 화면 정리

- 설명성·감성 문구 정리. 필요한 적용 범위와 무입력 재울림 안내는 유지.
- 밝은 바탕, 얇은 테두리, 작은 모서리와 보라색 강조.
- 가로 목록/편집 분할, 세로 편집 전환, 좁은 창의 한 열 설정.
- 날짜·시계와 큰 미션 버튼 유지. 자세한 설계는 UI-DESIGN.md 참고.

## 빌드

프로젝트 `.tools/`의 JDK 17, Gradle 8.9, Android SDK 35를 사용합니다.
PowerShell에서 `./build.ps1` 실행: APK 빌드, JVM 단위 테스트, Android lint.
실기기 테스트 APK 빌드: `./build.ps1 -Tasks assembleDebugAndroidTest`
다른 PC에서는 JDK 17과 Android SDK Platform 35를 준비하고 `JAVA_HOME` 및 `ANDROID_HOME`을 지정합니다.
SDK 위치는 `local.properties`의 `sdk.dir`로 지정해도 됩니다. 해당 파일과 `.tools/`는 저장소에서 제외됩니다.

```sh
# macOS / Linux
./gradlew assembleDebug testDebugUnitTest lintDebug
```

```powershell
# Windows
.\gradlew.bat assembleDebug testDebugUnitTest lintDebug
```

`build.ps1`은 이 프로젝트의 로컬 `.tools/` 환경을 사용하는 편의 스크립트입니다.

APK: `app/build/outputs/apk/debug/app-debug.apk`
실기기 테스트: `app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk`
일반 사용자 설치에는 첫 번째 APK만 필요합니다.

## 주의할 동작

복제한 알람은 꺼진 새 초안이며 저장 후 켜서 사용합니다.
시간·소리 등 변경 후에는 ‘저장’을 눌러야 예약에 반영됩니다.
날짜 예외는 켜진 모든 알람에 적용됩니다. 자세한 우선순위는 CHANGELOG.md에 명시했습니다.
기존 알람의 공휴일 옵션은 업데이트 시 자동으로 켜지지 않습니다.

재부팅 후 첫 잠금 해제 전 소리·미션 실행과 프로세스 종료 후 미션 진행 복원을 실기기에서 확인했습니다.
구현 및 한계는 RELIABILITY.md를 참고하세요.
밤새 절전 상태에서의 신뢰성은 계속 실사용 확인이 필요합니다.
